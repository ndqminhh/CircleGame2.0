# CircleGame



Welcome to our circle game! What this game does is:

* Uses Raylib to draw bouncing circles until they collide!

  * InitWindow with user selected values and title
  * Set Target FPS
  * Initializes  changeable variables for aspects like circle radius, color, etc.
  * Uses math to calculate various features such as speed, collision, distances, etc.
  * Draws two circles and runs a test with circles move around until they collide. 
  * Features randomized speed changes!

Thank you for checking out and downloading this project!
